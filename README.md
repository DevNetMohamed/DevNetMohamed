## 📂 Featured Projects

### 🏥 Hospital Management System
> **Stack:** NestJS · TypeScript · Apache Kafka · PostgreSQL · Docker · Kubernetes · Helm
- Microservices-based system (API gateway, auth service, roles module) using TypeORM, soft deletes, and Kafka event publishing on domain changes.
- Wrote a full Helm chart (configmap, secret, deployment, ingress, service) and deployed the stack — including Kafka, Zookeeper, Postgres, and Redis — into a local Kubernetes (kind) cluster.
- Built a self-hosted GitHub Actions CD pipeline that patches Helm values with `yq` and rolls out to the cluster.

### 🎫 EventFlow — Distributed Event-Driven Microservices
> **Stack:** NestJS · TypeScript · Apache Kafka · Drizzle ORM · PostgreSQL · Docker · Kubernetes
- Production-style event ticketing platform with Auth, Events, Tickets, and Notifications services communicating asynchronously over Kafka.
- Containerized every service with Docker and structured Kubernetes manifests for multi-environment deployment and scaling.

### 💬 Real-Time Chat Platform
> **Stack:** Node.js · TypeScript · RabbitMQ · Socket.io · MongoDB · Redis · Next.js
- TypeScript monorepo with user, chat, message, and mail services communicating over RabbitMQ, with a Next.js real-time frontend.
- Rebuilt the chat and message services from the ground up with Zod validation, typed Redis helpers, and a fixed single-reply-queue RabbitMQ utility.

### ⚙️ Nexus Repository Manager Automation with Ansible
> **Stack:** Ansible · Docker · Molecule · GitHub Actions
- Production-grade Ansible role for automated Sonatype Nexus 3 deployment and configuration, tested with Molecule and validated in CI, following Infrastructure-as-Code best practices.

### ☁️ AWS Infrastructure as Code
> **Stack:** Terraform · AWS (VPC, EC2, ALB, ElastiCache, SES, Route 53, IAM)
- Automated AWS infrastructure provisioning with Terraform — networking, security groups, load balancers, and ElastiCache caching layers — applying IaC principles for consistent, repeatable deployments.

### 🔧 Jenkins CI/CD Pipeline for AWS
> **Stack:** Jenkins · Ansible · Terraform · AWS · Node.js
- End-to-end pipeline automating Node.js app deployment to a private EC2 instance, with Ansible handling configuration, Jenkins driving branch-based pipelines, and Terraform managing the Application Load Balancer.

### 🛒 Full-Stack E-Commerce Platform
> **Stack:** Node.js · React · MongoDB · Docker Compose · GitHub Actions
- Full-stack e-commerce app with JWT authentication, role-based authorization, shopping cart, and order processing, deployed via automated CI/CD with Docker Hub integration.
